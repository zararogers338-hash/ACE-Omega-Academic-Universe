# Contributing / 贡献指南

Contributions are welcome. Useful contributions include:

- bug reports;
- parsing improvements;
- new visualization pages;
- better examples;
- documentation improvements;
- AI backend compatibility fixes;
- tests for data normalization and celestial property computation.

Please keep contributions safe:

- do not commit API keys;
- do not commit private datasets;
- do not commit large model files;
- do not add hidden network calls.

中文：欢迎贡献解析器、可视化页面、文档、示例数据和测试。请不要提交 API key、私有数据或大型模型文件。
