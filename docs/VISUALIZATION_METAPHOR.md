# Visualization Metaphor / 可视化隐喻

ACE-Omega uses a cosmic metaphor to make academic structure visible.

| Visual object | Meaning |
|---|---|
| Star / celestial body | Paper |
| Mass / radius | Citation influence |
| Height | Citation visibility |
| Module color | Research category |
| Black hole | Foundational or extremely influential paper |
| Dyson sphere | Paradigm-capturing high-impact work |
| Satellite ring | Follow-up cluster |
| Asteroid belt | Scattered low-impact fragments |
| Gravity grid | Warped attention / influence field |
| Timeline replay | Evolution of knowledge over time |

中文：这个系统用“天体”来解释论文结构，用“引力”来解释引用和注意力，用“星团”来解释学科聚类，用“时间线”来解释知识演化。
